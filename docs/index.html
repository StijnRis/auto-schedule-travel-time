What it does

Put a location on your events and the script handles the rest. It runs automatically whenever your calendar changes.

⏰

Tells you when to leave

Every travel block is titled like 🚲 Leave 08:42 · Biking, so a glance at your calendar or a notification is enough.

🧭

Picks the best way

Compares walking, biking, public transport, NS and driving. Short trips are walked, medium ones biked, and otherwise the fastest option wins.

🚆

NS journey planner

In the Netherlands, it plans door-to-door journeys with the official NS API: trains, tracks, transfers, fares and crowd forecasts.

🔗

One tap to directions

Every travel option is a link that opens that exact mode in Google Maps with arrive by set to your event, so traffic and timetables are right.

📍

Knows where you are

Back-to-back events? It routes from your previous event. Long gap? It assumes you went home. After the last event it plans your trip home.

✈️

Custom rules

Keyword rules like "arrive 2 hours early for anything titled flight, and don't plan a return trip".

Everything in the event

Open a travel block to see all options side by side. Each one is a link to that specific travel mode, and the chosen route comes with step-by-step directions.

1. Collect events from your calendars for the next 7 days
2. Work out where you're coming from (home or the previous event)
3. Ask Google Maps and NS for every travel mode, arriving on time
4. Pick the best mode and write a travel block to your travel calendar
5. Clean up blocks for moved or deleted events

Set it up

No servers, no subscriptions. It runs in your own Google account.

  1. Create a travel calendar

    In Google Calendar, add a new calendar called "Travel" and copy its Calendar ID (Settings → Integrate calendar).

  2. Copy the script

    Create a project on script.google.com and add the files from the src folder.

  3. Add your details

    Under Project Settings → Script Properties, add TARGET_CALENDAR_ID, HOME_LOCATION and optionally NS_API_KEY (free at apiportal.ns.nl).

  4. Run it

    Run processTravelBlocks once to grant permissions, then installTriggers to keep it running automatically.

Make it yours

Everything is configured in Config.gs.

// When to walk or bike
MODE_SELECTION: {
  walkIfUnderMinutes: 15,
  bikeIfUnderMinutes: 40,
  allowDriving: false
},

// Arrive 5 minutes early by default
ARRIVAL_BUFFER_MINUTES: 5,

// Special rules by keyword
SPECIAL_RULES: [
  {
    keywords: ['flight', 'vlucht'],
    arrivalBufferMinutes: 120,
    disableReturnHome: true
  }
]
